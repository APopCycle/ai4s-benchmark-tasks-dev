# AI4S formal tasks

This directory contains proposed AI4S benchmark tasks. The required path is:

```text
tasks/<domain>/<field>/<task-slug>/
```

Only tasks listed in `dataset.toml` belong to a release. During the Dev preview
that allowlist is intentionally empty; runnable examples live under
[`reference-tasks/`](../reference-tasks/README.md).

Start with the [quickstart](../docs/QUICKSTART.md), then follow the
[contribution guide](../CONTRIBUTING.md). Do not add a task implementation
before its Markdown proposal has been approved and merged.
